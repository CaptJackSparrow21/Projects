## Projects

### 1. YT Downloader

A native macOS application built using SwiftUI that makes downloading YouTube videos and playlists easier.

**Features**
- Download individual YouTube videos and playlists.
- Download videos in different resolutions, including up to 4K.
- Extract audio from videos.
- Download and embed subtitles.
- Monitor download progress, speed, and estimated time remaining.
- Manage multiple downloads.

**Technologies**
- Swift
- SwiftUI
- yt-dlp
- FFmpeg

**Platform:** macOS

**Source Code:** [YT Downloader](./Just%20for%20Fun/YT%20Downloader)
